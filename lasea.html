During my time at LASEA, I helped enhance KYLA®, a core software platform used for precision control of industrial laser machining systems. KYLA® integrates CAD/CAM workflows with real-time laser execution and machine feedback to support complex operations such as cutting, engraving, drilling, and more.



In this role I:

  • Improved and extended the existing control software that drives laser generation and machine coordination, increasing robustness and usability.
  • Played a key part in implementing a 3D generator component that allowed users to create and preview three-dimensional machining models directly in the software.
  • Worked closely with cross-functional teams to ensure seamless integration between the new 3D generation module, machine communication layers, and user interface components.
  • Used C# and WPF throughout to develop performant, maintainable features in a high-precision industrial context.

This work contributed to a more capable, intuitive laser machining suite that bridges design and real-world production with powerful software tools.
