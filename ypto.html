Senior Software Developer – Railway Operations Platform (2025–Present)

At YPTO, I work on EShuning, a railway management system used to support operational and service-oriented workflows within the Belgian rail ecosystem.

In this role I:

  • Improved the performance and usability of the railway management platform, focusing on maintainability and end-user efficiency.
  • Led the end-to-end development of the carwash feature, from functional design through implementation and delivery.
  • Managed and evolved APIs, collaborating closely with backend teams to optimize system integrations and data flows.
  • Oversaw mobile-oriented design, ensuring consistent behavior, responsiveness, and usability across devices.
  • Actively contributed to modern development practices, leveraging AI-assisted tools to improve productivity and code quality.

The solution is built using C# (.NET 9), Blazor, MudBlazor, xUnit, Azure API Management, and Azure DevOps, with Jira and Confluence for project coordination. Daily development is supported by GitHub Copilot, ChatGPT, and Claude Code, enabling faster iteration and higher-quality delivery in a complex enterprise environment.
